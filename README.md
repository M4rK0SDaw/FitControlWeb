# FitControl Web

FitControl Web es una aplicacion web para la gestion integral de un gimnasio.

## Funcionalidades principales

- Autenticacion con roles: administrador, entrenador y cliente.
- Gestion de usuarios, entrenadores, especialidades y metodos de pago.
- Gestion de clases, horarios, aforo y reservas.
- Suscripciones, facturas y pagos con Stripe en modo test.
- Correos de bienvenida, bloqueo/recuperacion y pago confirmado.
- Chat interno mediante SignalR.
- Dashboards por rol.
- Exportaciones a CSV, Excel y PDF.

## Tecnologias

- ASP.NET Core MVC
- Entity Framework Core
- SQL Server / SQL Express
- Razor Views
- Bootstrap
- SignalR
- Stripe
- SMTP Gmail
